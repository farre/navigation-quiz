Session History and Navigation — Navigation API

“Aborting” navigations

Aborting navigation vs aborting the ongoing navigate event

Things that cancel ongoing navigate event

  • Reject an navigate commit/intercept/precommit handler (names are hard here)
  • Remove an iframe
  • Call window.stop()
  • Firing new navigate events, because navigation can start from other event handlers including from the currently dispatching navigate event
  • etc
  • Canceling the onnavigate is not the same as stopping the ongoing navigate event
